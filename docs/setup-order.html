Setup Order Runbook: 10 Mandatory Steps

Android security frameworks enforce rigid dependency chains. Follow this numbered sequence exactly from Step 1 to Step 10.

Why Order Strictly Matters:
• Provisioning Device Owner fails if any user account is already configured on the handset.
• Arming Hardware Factory Reset Protection (FRP) requires linking a Google account after Device Owner is set.
• Initializing Android Keystore hardware-bound credentials requires a device PIN/Biometric lock to exist before vault secrets are stored.

Step 1: Factory Reset Test Phone (Zero Accounts)

Perform a complete factory reset on the handset to protect. Complete the initial setup wizard (Language, Wi-Fi).
CRITICAL: DO NOT ADD A GOOGLE ACCOUNT OR ANY OTHER ACCOUNT. Skip account setup. If any account exists, Android will reject Device Owner provisioning with IllegalStateException.

Step 2: Provision Device Owner Mode via ADB

Enable Developer Options and USB Debugging on the phone, connect via USB, and install Guardian:

adb install -r -g android/app-guardian/build/outputs/apk/direct/debug/app-guardian-direct-debug.apk
Handling Play Protect / OEM "High Risk" Warnings:
When sideloading pre-release binaries, Google Play Protect or OEM security managers (Xiaomi HyperOS, Samsung Knox, ColorOS, OriginOS) may warn that the app is "High Risk" due to its device admin and background location privileges. Using adb install -r -g automatically pre-grants runtime permissions and bypasses these prompts. If sideloading manually on the device: • Play Protect: Tap "More details" → "Install anyway".
• Xiaomi HyperOS/MIUI: Wait for the 10-second timer → Check "I am aware of risks" → "OK".
• Samsung Galaxy: Tap "More options" → "Install anyway".

Provision Device Owner component:

adb shell dpm set-device-owner com.antitheft.guardian/com.antitheft.deviceowner.AntiTheftDeviceAdminReceiver

Verify that terminal returns: Success: Device owner set to package...

Step 3: Link Your Google Account (Arms Hardware FRP)

Now that Device Owner is anchored in the OS, go to Settings → Passwords & Accounts → Add Google Account. Linking your account now arms Factory Reset Protection (FRP). If a thief forces a hardware wipe in recovery mode, Android demands your Google credentials before booting.

Step 4: Configure Device Screen Lock (PIN / Fingerprint)

Set a strong screen lock PIN (minimum 6 digits) and enroll biometrics. This is required for Android Keystore hardware-backed keys and arms the 3-wrong-attempt intruder photo capture trigger.

Step 5: Grant Runtime Permissions & Disable Battery Optimization

Grant all required permissions via ADB or manual prompt:

for p in ACCESS_FINE_LOCATION ACCESS_COARSE_LOCATION ACCESS_BACKGROUND_LOCATION POST_NOTIFICATIONS READ_PHONE_STATE SEND_SMS RECEIVE_SMS CALL_PHONE CAMERA; do adb shell pm grant com.antitheft.guardian android.permission.$p 2>/dev/null done

Go to Settings → Apps → Guardian → App battery usage → Unrestricted.

Step 6: Install & Initialize the Admin Companion App

Install the Admin Companion app on your secondary/controller phone:

adb install -r android/app-admin/build/outputs/apk/debug/app-admin-debug.apk

Forward port (for local development testing):

adb reverse tcp:8000 tcp:8000

Open Admin App, log into your owner account, enroll Two-Factor Authentication (TOTP), and save your 8 recovery codes.

Step 7: Perform Mutual Camera QR Pairing

In the Admin App, tap Pair New Device. Enter your Admin phone number and generate the pairing QR code. In Guardian, tap Pair with Admin and scan the QR code. Confirm the mutual 3-digit visual verification code on both screens.

Step 8: Configure Trusted Emergency Contacts

In Guardian settings, save your trusted emergency contact number in full international E.164 format (e.g., +919876543210). This number receives automated SMS coordinates upon theft.

Step 9: Arm the Encrypted Recovery Vault

In the Admin App, open Recovery Vault. Authenticate with biometrics and store your handset's IMEI 1, IMEI 2, serial number, and secondary recovery codes. Set a strong master passphrase (≥16 chars) and write it down on physical paper.

Step 10: Run the "Test Mode" Drill

Verify functionality without causing a real panic: in the Admin App, select TEST_MODE (Drill). The Guardian handset will play a 10-second audible siren and voice announcement at maximum volume, updating its live GPS fix on your dashboard while sending zero emergency SMS messages to family contacts.
