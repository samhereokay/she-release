Data Privacy & Security Architecture

A plain-language breakdown of how SHE protects your personal data, guarantees zero telemetry, and enforces zero-knowledge encryption.

1. Zero Telemetry & Advertising Commitment

SHE is built strictly for handset defense, not data collection. Our applications and backend contain:

  • Zero Third-Party Trackers: No Google Analytics, Firebase Analytics, Crashlytics, or user tracking SDKs.
  • Zero Advertising SDKs: No advertising networks, behavioral profiling, or device fingerprinting.
  • Zero Data Monetization: Your handset locations, identity documents, and recovery records are never sold, analyzed, or shared with third parties.

2. Zero-Knowledge Cryptographic Vault

When you store IMEI numbers, recovery keys, or purchase invoices in the Recovery Vault:

  • Client-Side Encryption: All encryption is performed directly on your Android controller device before data leaves the handset.
  • Military-Grade Algorithms: Uses AES-256-GCM authenticated encryption with PBKDF2 key derivation (600,000 iterations and 128-bit random salts).
  • Opaque Server Storage: The backend database only ever stores base64-encoded ciphertext envelopes, initialization vectors (IVs), and authentication tags. Even with full database access, server operators cannot decrypt your secrets.

3. Handset Location Telemetry Retention (30-Day Purge)

Location data is sensitive. SHE enforces strict telemetry controls:

  • Scoped Strictly to Paired Owners: Only the authenticated owner of a device can query its GPS coordinates. Cross-user access is blocked at the API authorization layer.
  • Automated Rolling Purge: 30-day rolling purge automatically removes historical GPS coordinate fixes older than 30 days from the database.
  • Direct Boot Separation: Before the first unlock, location coordinates are stored strictly in Device Encrypted Storage to prevent unauthorized local extraction.

4. Authentication & Key Management

  • Password Protection: Owner account passwords are hash-protected using the memory-hard Argon2id algorithm.
  • Encrypted TOTP Secrets: Two-Factor Authentication shared secrets are encrypted at rest on the server using AES-256 before database insertion.
  • Argon2id Single-Use Recovery Codes: 8 emergency recovery codes are generated as salted Argon2id hashes. Once used to log in during a theft crisis, the code is permanently destroyed.

5. SMS Channel Privacy & Zero-Retention OTP Protection

When offline SMS fallback is enabled, SHE enforces strict privacy controls to prevent message interception and spam:

  • Zero Inbox Access: SHE does not request android.permission.READ_SMS. It cannot read stored messages, SMS history, or personal conversations.
  • Zero-Retention OTP Discard: Inbound messages that do not start with AT1:CMD: (such as banking OTPs, 2FA codes, or personal chats) are immediately discarded from memory in 0 microseconds without being logged or parsed.
  • Strict Recipient Pinned to Trusted Admin: Outgoing SMS can only ever be sent to the paired Admin Companion phone number. It cannot send messages to arbitrary third parties or premium-rate numbers.
  • Zero Link Launching Capabilities: Guardian contains zero WebViews and zero browser intents; it is incapable of opening web links.
  • 100% Optional: SMS permissions are completely optional. If denied, the entire ecosystem continues to operate normally over Wi-Fi and mobile data.

6. Open-Source Transparency & Self-Hosting

Trust is verified through source code, not marketing claims:

  • 100% Open-Source: Published under the permissive Apache 2.0 open-source license. Every line of backend and Android client code is available for independent security audits.
  • Self-Hostable: You can host the SHE FastAPI backend on your own private virtual server or home Raspberry Pi, retaining complete sovereignty over your data.
